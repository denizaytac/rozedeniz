## Project Overview

This project is a modern, bilingual wedding website for "Roze & Deniz". It is a static website built with vanilla HTML, CSS, and JavaScript, with no external dependencies or build process. The design is elegant and minimalist, inspired by "Sex and the City".

The website is available in German and Turkish. It features a hero section with a photo, a personal message, a timeline of the wedding day, and an FAQ section.

## Key Files

*   `index.html`: The main HTML file, containing the structure of the website.
*   `style.css`: The stylesheet, defining the visual presentation of the website. It uses CSS variables for easy customization of colors and spacing.
*   `script.js`: The JavaScript file, handling the interactivity of the website, including the multi-language functionality, the wedding countdown, and the FAQ accordion.
*   `README.md`: The project's documentation, with instructions on how to customize the website.

## Development Conventions

The code is well-structured and follows good practices. The HTML is semantic, the CSS is organized and uses variables, and the JavaScript is clean and modular. The project is simple and easy to understand, making it easy to maintain and customize.

## Building and Running

To run the website locally, simply open the `index.html` file in a web browser. No build process is required.
